# FreshCart React

Install Node.js LTS, extract this folder, open it in VS Code and run `npm install`, then `npm run dev`. Open the localhost URL. On Windows PowerShell, use `npm.cmd` if script execution is blocked. Build with `npm run build` (output dist). Vercel: framework Vite, output dist.

Uses React Router and fetch. Default API: https://ecommerce.routemisr.com/api/v1 (override with VITE_API_URL in .env). Live backend availability, CORS, authentication, and endpoint compatibility need testing. No mock products or fake orders. Cash checkout only. Demo could not be accessed, so design is an independent recreation, not verified pixel matching. API documentation was not readable, so endpoints are based on common Route API conventions and not verified. No claim of completed acceptance testing.
